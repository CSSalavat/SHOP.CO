# SHOP.CO
Учебный проект. Специально тренировался верстать сетки на флексах и разбирался с классами по БЭМу.

### Важное примечание:
На обе страницы не успел сделать мобильный адаптив из-за жесткого дедлайна. Первую страницу (сам каталог) в итоге успел вылизать нормально и аккуратно, всё стоит по сетке. А вот вторую страницу доделывал уже в самый последний момент и в спешке, поэтому она вышла кривоватой. Прошу прощения, что не всё успел довести до ума.
Переводчик и Google использовал только для того, чтобы использовать правильные имена классов по БЭМу на английском языке для обеих страниц. Дальше всю логику, макет и костыли дописывал сам руками.

### Что внутри:
В проекте полностью сверстаны две страницы, но вторая из-за спешки получилась кривоватой

### По коду:
Только чистый HTML и CSS.
Открывать через index.html.
